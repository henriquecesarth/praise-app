1. **Historical link aliases:** `RepertoireRepository.ts` categorizes YouTube, MP3 and Chord links with `isCustom: true` as external links. Resubmitting unchanged links while renaming a version can clear `youtube_url`, `audio_url` or `chord_sheet_url` and change YouTube filtering. Preserve historical alias mappings and add regression coverage. For each alias, seed the matching flat field and primary link with the same old URL and `isCustom: true`; rename the version while resubmitting its links; assert the matching flat URL survives. All three independent cases failed.
2. **Orphan classification preservation:** the actual title-only Web form can resend unchanged primary `classificationIds: []` / `classification_ids: []` with no flat classification field. Given an existing flat `classification_id: 'deleted'`, the Backend clears it to null. Preserve unchanged form data separately from intentional removal. Seed that flat orphan with empty primary classifications, submit the actual title-only payload, and assert persistence retains `'deleted'`. This persistence assertion failed; the Web wire-payload capture passed.

Independent supplementary Backend evidence: **4 failed / 1 passed** (three aliases, one orphan preservation failure; moving an orphan secondary classification to primary was correctly rejected). Temporary supplementary executable test snapshots were not retained. Their useful reproduction source/inputs are preserved here; do not claim those regressions pass.
