# M20-C14 R5 - Gate 3

Scope: PDF configuration, explicit generation, paginated preview and download. Gates 1/2 WIP preserved. No API/backend/mobile/auth changes, no deployment, no Gate 4.

Implementation:
- SmartChordPdfSettings extracts the existing six fonts, 10-24px size, shared 0-24px spacing in steps of 2 and per-user marker. No second spacing preference.
- Both workspace modes open the same accessible configuration dialog. Focus trap, Escape, Cancel and unsaved-content explanation are included.
- Only Generate and view opens a generation request. Cache invalidation and generation effects are separate; changing settings does not rasterize or count pages.
- Existing html2pdf/jsPDF/canvas page slicing retained, including A4 10mm margins, compact header, transposition, chord alignment and tablatures.
- Signature is a JSON tuple covering user, ministry, document identity and all effective document/settings fields. Generation checks the latest signature and generation counter before publishing results. Closed/stale requests cannot publish or download.
- Download uses the cached object URL of the preview Blob. Removed the fallback that could regenerate or download a different document. Generation failures are visible and retryable via settings.
- Preview offers real page count, Download, Close and return to settings. Page images fit viewport width at the original A4 ratio; scaling affects preview only. Source document is offscreen and excluded from accessibility.
